Buat aplikasi manajemen kantor modern seperti ERP/Odoo menggunakan Next.js + TypeScript + Supabase dengan tampilan premium, stylish, clean, modern, dan catchy. Gunakan desain dashboard profesional ala SaaS enterprise modern (kombinasi antara Odoo, Notion, Linear, dan Stripe Dashboard).

Spesifikasi teknis:

Framework: Next.js App Router
Language: TypeScript
Database & Auth: Supabase
Styling: Tailwind CSS
UI Components: shadcn/ui
Icons: lucide-react
State management: Zustand atau Context API
Charts: Recharts
Form validation: React Hook Form + Zod
Animasi halus menggunakan Framer Motion
Responsive untuk desktop, tablet, dan mobile
Struktur folder rapi dan scalable
